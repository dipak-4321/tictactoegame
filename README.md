# 🎮 Tic Tac Toe Game

A fun, interactive, and stylish Tic Tac Toe game built using **HTML, CSS, and JavaScript**. Play against a friend, track scores, and enjoy multiple rounds with a cool user interface.

## ✨ Features

* ❌⭕ **Two-Player Gameplay** – Players take turns as X and O.
* 🔄 **Reset Button** – Reset the current game board and start again.
* ▶️ **Next Game Button** – Start the next round while keeping the scores.
* 🏆 **Winner Detection** – Automatically detects the winning player.
* 🤝 **Draw Detection** – Identifies when the game ends in a draw.
* 📊 **Scoreboard** – Tracks the scores of both players across multiple rounds.
* 🎨 **Cool Design** – Modern, attractive, and visually appealing interface.
* ⚡ **Interactive Gameplay** – Smooth and responsive game interactions.
* 🔁 **Multiple Rounds** – Continue playing and compete for the highest score.
* 📱 **Responsive Design** – Designed to work on different screen sizes.

## 🛠️ Technologies Used

* **HTML5** – Structures the game interface.
* **CSS3** – Creates the design, layout, colors, and animations.
* **JavaScript** – Manages player turns, game logic, scores, and buttons.

## 🎯 How to Play

1. Open the game in your browser.
2. Player X starts the game.
3. Players take turns selecting empty cells.
4. The first player to get three marks in a row, column, or diagonal wins the round.
5. The winner receives one point on the scoreboard.
6. If all nine cells are filled without a winner, the round ends in a draw.
7. Click **Next Game** to start another round while keeping the scores.
8. Click **Reset** to clear the current board and start over.

## 🔘 Button Functions

| Button    | Function                                               |
| --------- | ------------------------------------------------------ |
| Reset     | Clears the current board and resets the current round. |
| Next Game | Starts a new round while preserving player scores.     |

## 📊 Score Tracking

The game maintains separate scores for Player X and Player O across multiple rounds.

* Player X earns a point when X wins.
* Player O earns a point when O wins.
* Draws do not award a point.
* Starting the next game preserves the scores.
